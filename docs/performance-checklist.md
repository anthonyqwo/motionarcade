# Performance Checklist

## 目的

這份文件用來記錄 Motion Arcade 的即時互動表現，包含 motion event 延遲、畫面流暢度與感測器取樣穩定度。

## 指標

| 指標 | 目標 | 說明 |
| --- | --- | --- |
| 手機送出到電腦收到 | 低於 100ms | WebSocket 傳輸與事件處理 |
| 手機動作到畫面反應 | 低於 200ms | 玩家主觀感受到的延遲 |
| 遊戲畫面 FPS | 盡量維持 60 FPS | 避免劍痕與方塊動畫卡頓 |
| 揮動偵測成功率 | 展示可接受 | 四方向測試至少各 20 次 |
| 重複觸發率 | 低 | 一次揮動不應觸發多個 slash event |

## 測試流程

1. 電腦端建立房間。
2. 手機端連線。
3. 手機端校正。
4. 連續向 left、right、up、down 各揮動 20 次。
5. 記錄方向辨識成功次數。
6. 記錄平均延遲與最大延遲。
7. 遊玩 Motion Saber 2 分鐘。
8. 觀察 FPS、卡頓、斷線與誤判。
